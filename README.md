## 🌐 About the Project

Welcome to my personal developer portfolio!

This website is designed to showcase my technical journey as a Computer Science and Engineering student specializing in Artificial Intelligence and Machine Learning.

Built with a modern frontend stack, the portfolio features a futuristic dark interface, animated particle visuals, video backgrounds, and interactive sections to create an immersive browsing experience.

- 🎨 Futuristic dark-themed user interface
- 🌌 Animated particle-inspired visual experience
- 🎥 Full-screen hero video introduction
- 💻 Dedicated sections for About, Skills, Projects, Experience, and Achievements

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/ajaytilak341/Portfolio.git
```

### 2. Navigate to the project directory

```bash
cd Portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

Visit:

```text
http://localhost:3000
```
